# Prioritize task success over a fixed token-growth ceiling

Task Execution Success Rate is the primary optimization outcome. Token usage remains measured and reported, but a Candidate is not rejected solely for exceeding a fixed token-growth ratio; Resource Guardrails instead detect consecutive No-progress Events and require replanning, strategy change, or termination so productive high-cost exploration remains possible without permitting runaway repetition.

## Consequences

Promotion still requires zero Stable-pass Regression and no uncontrolled No-progress loop. Cost, tool, latency, and visual-call metrics remain diagnostic evidence and can motivate later Profile changes without overriding verified success.
